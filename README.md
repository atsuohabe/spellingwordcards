# えいごカード（spellingwordcards）

小学生向けの英単語フラッシュカード Webアプリ。iPhone のブラウザで使うことを想定しています。

- **おもて** … 🔊 発音の再生ボタン（音声ファイル不要 / 端末の読み上げ機能を使用）
- **うら** … 英語のスペル（大）＋ 日本語の訳（小・マスタにある場合のみ）
- **⭕️ おぼえた / 🔁 まだ** … 「まだ」を選んだカードは、最後にまわして無くなるまでくり返し出題
- **じゅんばん / ランダム** … マスタの並び順そのまま or シャッフル
- **シート選択** … 毎週追加されるシートをホームから選択。前回のシート・途中の進み具合は端末に保存され「▶️ つづきから」で再開

ビルド不要・ライブラリ不使用の静的サイトです（HTML + CSS + ES Modules のみ）。

## ファイル構成

```
index.html          画面（ホーム / 学習 / おわり）
css/style.css       スタイル
js/config.js        ★設定ファイル（マスタの場所はここだけ書き換える）
js/data.js          マスタ読み込み（ローカルJSON / Googleスプレッドシート）
js/speech.js        発音再生（Web Speech API）
js/storage.js       選択シート・学習途中の保存（localStorage）
js/app.js           画面のうごき
data/               サンプルのマスタ（ローカルモード用）
```

## うごかしかた（ローカル確認）

`file://` では ES Modules と fetch が使えないため、簡易サーバー経由で開きます。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

公開は GitHub Pages（Settings → Pages → Branch: main / root）でそのまま使えます。

## マスタの用意

### A. Googleスプレッドシートを使う（毎週シートを追加していく運用・推奨）

1. スプレッドシートを1つ作り、**1週間ぶんを1シート**にします（シート名がそのままホームの選択肢になります。例 `Vol.1`）。
2. 各シートの1行目をヘッダーにします。現在のマスタの形（`spellingwordcards.xlsx`）がそのまま使えます。

   | No. | Word  | Translation |
   | --- | ----- | ----------- |
   | 1   | blade | 刃（は）    |
   | 2   | gray  | 灰（はい）色 |

   - 英語列は `Word` / `English` / `Spelling` / `英語` / `単語` などを、日本語列は `Translation` / `ja` / `Japanese` / `訳` / `意味` などを自動認識します。
   - ヘッダー名が想定外でも、中身を見て「英字だけの列＝英語」「かな漢字を含む列＝日本語」と判定します（`No.` のような番号列は選ばれません）。
   - 日本語の列は空でも構いません（うら面には英語だけ表示されます）。
   - 同じ単語が重複している行は自動で1つにまとめます。
3. 「共有」→ **リンクを知っている全員が閲覧可** にします。
4. `js/config.js` を書き換えます。

```js
export const CONFIG = {
  source: 'gsheet',
  gsheet: {
    spreadsheetId: 'スプレッドシートURLの /d/ と /edit の間の文字列',
    apiKey: '',          // 任意（下記参照）
    sheets: ['Week01'],  // apiKey を使わない場合は毎週ここに追加
    excludeSheets: ['設定'],
  },
  ...
};
```

- **apiKey を設定した場合**：シート名を自動取得するので、**スプレッドシートにシートを追加するだけ**でホームの一覧に増えます（おすすめ）。

  APIキーの作り方:
  1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
  2. 「APIとサービス」→「ライブラリ」→ **Google Sheets API** を有効化
  3. 「認証情報」→「認証情報を作成」→ **APIキー**
  4. 作成したキーを編集し、必ず次の2つを設定する
     - **アプリケーションの制限**: ウェブサイト（HTTPリファラー）→ `https://<ユーザー名>.github.io/*`
     - **APIの制限**: Google Sheets API のみ

  キーは公開ページのソースに含まれます。上の制限をかけていれば、他サイトからの利用も他API（課金対象）への流用も防げます。閲覧のみ・公開共有のスプレッドシートなので、キーから読めるのはこの単語リストだけです。
- **apiKey が空の場合**：`sheets` に書いたシート名だけが一覧に出ます（毎週1行追加）。

### B. リポジトリ内の JSON を使う（オフラインでも動く / 現在の初期設定）

`data/index.json` に一覧、`data/<id>.json` に単語を置きます。

```jsonc
// data/index.json
{ "sheets": [ { "id": "vol1", "name": "Vol.1" } ] }

// data/vol1.json
{ "cards": [ { "word": "blade", "ja": "刃（は）" } ] }
```

現在 `data/` に入っているのは `spellingwordcards.xlsx`（Vol.1 / Vol.2 各24語）から変換したスナップショットです。
Googleスプレッドシート運用に切り替えたあとは自動更新されないので、オフライン用の控えとして残しています。

## 設定できること（js/config.js）

| 項目 | 内容 |
| --- | --- |
| `speech.lang` | 読み上げの言語（既定 `en-US`） |
| `speech.rate` | 読み上げの速さ（既定 `0.85` = 少しゆっくり） |
| `autoSpeak` | カードが表示されたときに自動で1回読み上げる（既定 `true`） |

## iPhone で使うときのメモ

- Safari で開き、共有 →「ホーム画面に追加」でアプリのように全画面で使えます。
- iOS は最初のタップまで音が鳴らない仕様のため、「はじめる」を押した時点で音声を有効化しています。
- 音が出ないときは、本体の**消音スイッチ**と音量、`設定 → アクセシビリティ → 読み上げコンテンツ`（英語の声）を確認してください。
