# えいごカード（spellingwordcards）

小学生向けの英単語フラッシュカード Webアプリ。iPhone のブラウザで使うことを想定しています。

- **おもて** … 🔊 発音の再生ボタン（音声ファイル不要 / 端末の読み上げ機能を使用）
- **うら** … 英語のスペル（大）＋ 日本語の訳（小・マスタにある場合のみ）
- **⭕️ おぼえた / 🔁 まだ** … 「まだ」を選んだカードは、最後にまわして無くなるまでくり返し出題
- **じゅんばん / ランダム** … マスタの並び順そのまま or シャッフル
- **シート選択** … 毎週追加されるシートをホームから選択。前回のシート・途中の進み具合は端末に保存され「▶️ つづきから」で再開

ビルド不要・ライブラリ不使用の静的サイトです（HTML + CSS + ES Modules のみ）。

## ファイル構成

```
index.html          画面（ホーム / 学習 / おわり）
spellingwordcards.xlsx  マスタ（これを更新してアップロードする）
css/style.css       スタイル
js/config.js        ★設定ファイル（マスタの場所はここだけ書き換える）
js/data.js          マスタ読み込み（ローカルJSON / Googleスプレッドシート）
js/speech.js        発音再生（Web Speech API）
js/storage.js       選択シート・学習途中の保存（localStorage）
js/app.js           画面のうごき
data/               マスタから自動生成された単語データ（手で編集しない）
tools/xlsx_to_json.py   xlsx → data/*.json の変換スクリプト
.github/workflows/  xlsxのアップロードを検知して自動変換するGitHub Actions
```

## うごかしかた（ローカル確認）

`file://` では ES Modules と fetch が使えないため、簡易サーバー経由で開きます。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

公開は GitHub Pages（Settings → Pages → Branch: main / root）でそのまま使えます。

## マスタの用意

### A. xlsx をアップロードする（現在の方式）

**毎週の更新は「マスタの xlsx を GitHub にアップロードするだけ」です。** Google側の設定は一切必要ありません。

1. 手元の `spellingwordcards.xlsx` に、新しい週のシートを追加する（シート名がそのままホームの選択肢になります。例 `Vol.3`）
2. GitHub のリポジトリ画面で **Add file → Upload files** から、同じファイル名でアップロードして Commit
3. あとは自動です。GitHub Actions が `tools/xlsx_to_json.py` を実行して `data/*.json` を作り直し、コミットします（1分ほど）
4. うまくいったかは、リポジトリの **Actions** タブで緑のチェックが付いているかで確認できます

シートの中身は次の形にしてください（現在のマスタの形そのままです）。

| No. | Word  | Translation |
| --- | ----- | ----------- |
| 1   | blade | 刃（は）    |
| 2   | gray  | 灰（はい）色 |

- 英語列は `Word` / `English` / `Spelling` / `英語` / `単語` などを、日本語列は `Translation` / `ja` / `Japanese` / `訳` / `意味` などを自動認識します。
- ヘッダー名が想定外でも、中身を見て「英字だけの列＝英語」「かな漢字を含む列＝日本語」と判定します（`No.` のような番号列は選ばれません）。
- 日本語の列は空でも構いません（うら面には英語だけ表示されます）。
- 重複した単語・空行は自動で取り除かれます。
- `設定` という名前のシートと、非表示にしたシートは一覧に出ません。
- シートを削除したり名前を変えたりした場合は、古いデータも自動で片付きます。

手元で試したいときは、同じ変換をそのまま実行できます。

```bash
python3 tools/xlsx_to_json.py
```

### B. Googleスプレッドシートを使う（任意）

1. スプレッドシートを1つ作り、**1週間ぶんを1シート**にします（シート名がそのままホームの選択肢になります。例 `Vol.1`）。
2. 各シートの1行目をヘッダーにします。現在のマスタの形（`spellingwordcards.xlsx`）がそのまま使えます。

   | No. | Word  | Translation |
   | --- | ----- | ----------- |
   | 1   | blade | 刃（は）    |
   | 2   | gray  | 灰（はい）色 |

   - 英語列は `Word` / `English` / `Spelling` / `英語` / `単語` などを、日本語列は `Translation` / `ja` / `Japanese` / `訳` / `意味` などを自動認識します。
   - ヘッダー名が想定外でも、中身を見て「英字だけの列＝英語」「かな漢字を含む列＝日本語」と判定します（`No.` のような番号列は選ばれません）。
   - 日本語の列は空でも構いません（うら面には英語だけ表示されます）。
   - 同じ単語が重複している行は自動で1つにまとめます。
   > **重要**: ファイルが **Googleスプレッドシート形式** である必要があります。
   > Excelファイル（.xlsx）をドライブにアップロードしただけの状態では、スプレッドシートの画面で開けても
   > 読み取りAPIからは扱えません（URLに `rtpof=true` が付いていたらこの状態です）。
   > その場合は開いたあと **ファイル → Googleスプレッドシートとして保存** を実行し、
   > 新しく作られたファイル（URLのIDが44文字になります）を使ってください。

3. 「共有」→ **リンクを知っている全員が閲覧可** にします。
4. `js/config.js` を書き換えます。URLはアドレスバーからそのままコピーでOKです。

```js
export const CONFIG = {
  source: 'gsheet',
  gsheet: {
    spreadsheetUrl: 'https://docs.google.com/spreadsheets/d/xxxxxxxx/edit',
    apiKey: 'AIza...',   // 下記参照
    sheets: [],          // apiKey がある場合は不要
    excludeSheets: ['設定'],
  },
  ...
};
```

- **apiKey を設定した場合**：シート名を自動取得するので、**スプレッドシートにシートを追加するだけ**でホームの一覧に増えます（おすすめ）。

  APIキーの作り方:
  1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
  2. 「APIとサービス」→「ライブラリ」→ **Google Sheets API** を有効化
  3. 「認証情報」→「認証情報を作成」→ **APIキー**
  4. 作成したキーを編集し、必ず次の2つを設定する
     - **アプリケーションの制限**: ウェブサイト（HTTPリファラー）→ `https://<ユーザー名>.github.io/*`
     - **APIの制限**: Google Sheets API のみ

  キーは公開ページのソースに含まれます。上の制限をかけていれば、他サイトからの利用も他API（課金対象）への流用も防げます。閲覧のみ・公開共有のスプレッドシートなので、キーから読めるのはこの単語リストだけです。
- **apiKey が空の場合**：`sheets` に書いたシート名だけが一覧に出ます（毎週1行追加）。

### C. JSON を直接置く

`data/index.json` に一覧、`data/<id>.json` に単語を置きます。

```jsonc
// data/index.json
{ "sheets": [ { "id": "vol1", "name": "Vol.1" } ] }

// data/vol1.json
{ "cards": [ { "word": "blade", "ja": "刃（は）" } ] }
```

通常は方式Aの自動変換で作られるので、手で書く必要はありません。

## 設定できること（js/config.js）

| 項目 | 内容 |
| --- | --- |
| `speech.lang` | 読み上げの言語（既定 `en-US`） |
| `speech.rate` | 読み上げの速さ（既定 `0.6`）。小さいほどゆっくり、`1.0` がふつうの速さ |
| `speech.preferVoices` | 使いたい声の名前を優先順に並べる。端末にある声から自動で選ばれる |
| `autoSpeak` | カードが表示されたときに自動で1回読み上げる（既定 `true`） |
| `autoSpeakDelay` | 次のカードが出てから読み上げるまでの間（既定 `1500` ミリ秒）。大きくするとより余裕ができる |
| `gsheet.excludeSheets` | ホームの一覧に出さないシート名 |

## うまく読み込めないとき

ホーム画面にエラーの内容が日本語で表示されます。

| 表示 | 原因と対処 |
| --- | --- |
| 単語が増えない（方式A） | Actions タブで失敗していないか確認。Actions が無効なら Settings → Actions → General で有効化する |
| 読む権限がありません | 共有が「リンクを知っている全員が閲覧可」になっていない／APIキーのリファラー制限に公開ページのURLが入っていない |
| スプレッドシートが見つかりません | URL（ID）が違う。または .xlsx のままのファイルを指している（→ Googleスプレッドシートとして保存） |
| APIキーが正しくない | `apiKey` の値、または Sheets API が有効化されているかを確認 |

## 公開する（GitHub Pages）

公開URL: **https://atsuohabe.github.io/spellingwordcards/**

初回だけ、リポジトリの設定画面で次の操作が必要です。

1. **Settings → Pages** を開く
2. **Source** で `Deploy from a branch` を選ぶ
3. **Branch** を `main` / `/ (root)` にして **Save**
4. 1〜2分待つと上記URLで開けるようになります

以降は `main` が更新されるたびに自動で再公開されます（xlsxをアップロードすると、変換→コミット→再公開まで自動）。

iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」しておくと、アプリのように使えます。

## iPhone で使うときのメモ

- Safari で開き、共有 →「ホーム画面に追加」でアプリのように全画面で使えます。
- iOS は最初のタップまで音が鳴らない仕様のため、「はじめる」を押した時点で音声を有効化しています。
- 音が出ないときは、本体の**消音スイッチ**と音量、`設定 → アクセシビリティ → 読み上げコンテンツ`（英語の声）を確認してください。

### 発音をより自然な声にする（おすすめ）

iPhone の標準の英語音声は簡易版のため、機械的に聞こえます。**高品質な音声を無料でダウンロード**できます。

1. `設定` → `アクセシビリティ` → `読み上げコンテンツ` → `声` → `英語`
2. 声の名前（`Ava` / `Samantha` など）をタップ
3. `拡張` または `プレミアム` と書かれたものを選んでダウンロード（数十MB）
4. ダウンロードした声を選択して完了

アプリ側は、端末にある中でいちばん品質の高い英語の声を自動で選ぶようになっているので、
ダウンロードするだけで発音が切り替わります（`speech.preferVoices` で優先順を変えられます）。
